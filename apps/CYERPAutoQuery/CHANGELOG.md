# CYERPAutoQuery Changelog

## V0.3.0

- Build 3（2026/10/16）：依使用者確認，移除 AUTOQUERY 本機歷史異動日期未選時自動補「近一年」：兩欄都沒勾選就不對 ERP 起／迄日期欄送出按鍵，只有一欄有選時只輸入那一欄，按 Enter 並讀回確認；不再為空日期做讀回檢查。CY Web 仍由 Worker 計算日期（含既有起日加一天），Agent 必須使用 CY Web 已補齊的完整起／迄日，缺漏則拒收，避免兩邊重複計算。批號查詢及 CY Web 不變。

- Build 2（2026/10/16）：修正 INVQ01「查歷史異動」的分段日期輸入：先點起日年份位置，依次送出 8 個數字實體按鍵（yyyyMMdd）並按 Enter 確認、讀回驗證，再對迄日執行相同動作。移除原本 End/Backspace 清空及包含「/」的逐字輸入，避免 ERP 年月日遮罩錯位；讀回不一致時立即停止，不會按「開始查詢」。本機未選日期時，「近一年」改成去年的同月同日，例如 20251016 → 20261016。CY Web 若傳入明確日期仍原樣採用；批號查詢不變。

- Build 1（2026/10/16）：新增 INVQ01 庫存狀況查詢（使用者要求）。INVI02 轉出後，若「批號管理」不是 N，從 Ribbon「串查」→「庫存狀況查詢作業」（取最上面那個）開啟 INVQ01，確認帶出相同品號後最大化，點「查各批庫存量」→「開始查詢」→ 等 ERP 標題變成「…-查各批庫存量」並跳到查詢結果 →「轉出到Excel」→ 讀取批號、庫存數量、入庫日、有效日期。勾選「查歷史異動」時再點「查歷史異動」、填入選擇日期起／迄（未勾日期為最近一年，最多三年，讀回確認）→ 開始查詢 → 轉出，讀取日期、單別-單號-序號（去除 ERP 補的空白）、庫別、庫別名稱、入出別、異動數量、備註；單位成本、異動金額不讀。用完以關閉視窗訊息關閉 INVQ01（失敗或 Esc 亦同）。頁籤以量測的各頁籤中心點擊（頁籤寬度隨文字），未切換再 OCR；轉出到Excel 的設定視窗尚未實機看過，程式自動辨識 ERP 匯出設定或 Windows 另存新檔，並把子視窗寫入 LOG。主視窗新增「查歷史異動」與起迄日期選擇器；下方改為「庫別／批號／歷史異動」三個頁籤。Web 查詢：claim 可帶 includeHistory／historyFrom／historyTo，回報加上 batchManaged、batches 與 history（欄位＋列，最多 2,000 列保留最新）；舊版 CY Web 會忽略新欄位。

## V0.2.0

- Build 4（2026/10/16）：依使用者要求移除「複製明細」按鈕（連同 TSV 輸出）。Build 3 實機：本機 A00124 與 Web C00154 查詢全程成功（約 7 秒）。
- Build 3（2026/10/16）：Build 1 實機：查詢的品號剛好是畫面上那一筆時，表頭立刻相符、ERP 尚未跳到「資料瀏覽」，「基本資料1」看起來仍顯示而沒有點擊，結果從資料瀏覽轉出（只有單頭、沒有單身頁籤）。改為查詢後先等 ERP 顯示「資料瀏覽」（最多 3 秒），一律點擊「基本資料1」並確認穩定，按 Ribbon Excel 前再確認一次仍在基本資料1，否則停止。
- Build 2（2026/10/16）：使用者要求。沒有 INVI02 視窗時，從 ERP 主視窗（鼎新電腦Conductor）Ribbon「作業速查」（OCR 定位）輸入 INVI02（讀回確認）→ Enter 自動開啟，最多等 30 秒；開著多個 INVI02 時，使用第一個（最上層）處於檢視狀態的視窗，都不在檢視狀態才停止。狀態標籤在多個視窗中有一個可用時顯示「檢視」。
- Build 1（2026/10/16）：V0.2.0 實機回報。匯出設定的「全選／清除／確定」是 TBitBtn 視窗，按鈕辨識補上 TBitBtn，不再走 OCR；單頭／單身是 TcxPageControl（單身頁點過才建立），改回量測座標點擊、以「該頁出現且可見」確認，OCR 只作備援，省下每步約 2 秒。「檢視Excel資料?」只認有 No 按鈕的新視窗（Build 0 把 ERP 的「處理進度」小視窗誤當成問題框），OCR 備援延後 8 秒且須讀到「檢視」才點；匯出完成等待延長為 60 秒、回答後等待 15 秒、匯出設定出現後先等 0.5 秒。匯出路徑改為貼上（EM_SETSEL＋WM_PASTE，事後還原剪貼簿），不再逐字輸入。
- Build 0（2026/10/16）：新增 CY Web 查詢連線（Agent）。依 chihyuan-web #169 的 ERP 品號查詢 contract：程式定時（閒置 3 秒）向 CY Web 領取查詢工作，用與本機相同的查詢流程執行（同樣鎖滑鼠、中央提示），回報 FOUND／NOT_FOUND／FAILED；失敗只回固定錯誤代碼（ERP_NOT_OPEN／ERP_BUSY／ERP_STATE／EXPORT_FAILED／CANCELLED／INTERNAL），不送出本機訊息。網路錯誤 3→30 秒退避；Token 被拒即停止；本機查詢中不領工作。主視窗新增「Web 連線」設定（網址、Token、啟用），Token 以 Windows DPAPI 加密存在程式旁 `config/agent.json`，狀態列顯示 Web 連線狀態。已對本機執行的 chihyuan-web #169 Worker（local D1）實測領取與回報成功。
- 同版修正（V0.1.0 Build 3 實機回報）：匯出設定的「單頭／單身」頁籤與「全選」「確定」按鈕在使用者電腦上不是視窗控制項（LOG：tabs not found as windows），改為找不到控制項時以 OCR 找文字點擊；「檢視Excel資料?」改以新出現的小視窗辨識，No 按鈕找不到控制項時同樣用 OCR。找不到時 LOG 列出對話框子視窗。

## V0.1.0

- Build 3（2026/10/16）：品號比對改為區分大小寫（使用者確認 SMART ERP 品號區分大小寫，小寫 c00154 查不到 C00154），與 CY Web contract 一致。程式圖示改用 AITeam CY Icon Family 的 `AutoQ`（AITeam#74，使用者確認：沿用 AutoInput 的 Auto 字樣與橘色，下方改為大 Q），由 `tools/fetch-canonical-icon.ps1` 依固定 revision 下載並核對 SHA-256，嵌入 EXE、視窗與工作列。實機 Build 2 按 F6 後回報「3 秒內沒有出現設定查詢條件」，但視窗其實約 4 秒後才出現（LOG：F6 12:03:48.457、失敗 51.519、狀態 52.547 轉為對話框開啟）。等待改為 10 秒；查詢條件視窗改以「一般選項」頁籤辨識（標題比對為輔，也找 INVI02 內的子視窗），匯出設定視窗改以「儲存檔案」路徑欄辨識；找不到時 LOG 列出 ERP 所有可見視窗。點擊遮擋檢查改為只認真正的子視窗，不把 ERP 彈出視窗當成 INVI02 的一部分。
- Build 2（2026/10/16）：查詢結果只保留使用者指定的欄位（`ItemFieldCatalog`，本機畫面與之後 Web 白名單共用）：品號、品名、規格、單位、庫存數量、商品分類（ERP「商品」＋料件分類三名稱）、商品描述、條碼編號、批號管理、有效天數、主供應商（＋名稱）、標準進價、標準售價、售價定價一～六；庫別：庫別、庫別名稱、儲位、安全存量、經濟批量、上次盤點日、最近入庫日、最近出庫日。其他匯出欄位（成本、庫存金額等）解析後即丟棄；匯出缺少清單欄位時停止並列出缺少的欄位。
- Build 1（2026/10/16）：資料改由 ERP「轉出至 Excel」取得（使用者發現匯出更乾淨、不會錯）：查到品號後切到「基本資料1」→ Ribbon「Excel」→「轉出至 Excel」→ 單頭與單身各按「全選」→ 儲存檔案填入程式旁的 `TEMP` 資料夾 → 確定 →「檢視Excel資料?」按 No → 讀取單頭資料（約 150 個具名欄位）與單身資料（庫別）後立即刪除檔案。不再逐頁籤讀取畫面欄位；主視窗改列「欄位／內容」與庫別表。Ribbon 與選單以 OCR 找文字（同 CYERPAutoInput 的列印）。
- Build 0（2026/10/16）：初版。輸入品號 → 找到唯一的 ERP「品號資料建立作業 (INVI02)」並最大化 → F6 開啟「設定查詢條件」→ 切到「一般選項」→ 品號條件設為「=」並輸入品號 → 確定 → 核對表頭品號 → 依序點「基本資料1」「基本資料2」「採購生管1」「售價」讀取欄位 → 在主視窗列出表頭與明細（可複製到 Excel）。查無品號（ERP 轉到資料瀏覽、表頭空白）時顯示「查無此品號」。介面比照 CYERPAutoInput（工具列＋ERP 狀態標籤＋群組＋狀態列）；查詢期間鎖定實體滑鼠、畫面中央顯示「自動查詢中」。頁籤以固定座標點擊、未切換時改用 OCR 找頁籤文字；查詢中可按 Esc 中止。
