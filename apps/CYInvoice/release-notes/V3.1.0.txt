CYInvoice V3.1.0 正式版

本 Minor 版本完成 V3.1 非折讓跨機人工協作：CYID 雲端模式下，員工可將紙本證明聯尚未收回的作廢申請及非折讓同步例外，以不可反查來源摘要手動回報跨機。管理員可依清單或工作項目 ID 查詢，進行 open→review→closed 人工覆核，版本競爭由 CAS 控制，異動留下不可刪改稽核紀錄。
跨機待辦的資料最小化、角色及裝置權限重驗、結果不明只讀查回、不重送官方交易等安全界線均保留；人工封存不代表 AMEGO 官方作廢或上傳成功。
V3.1-D 原有 CYInvoice Cloudflare D1／Worker 的 schema16 受控切換，已由使用者本機 MCP 回報完成；Windows 正式發布不重複部署或遷移。折讓 API 留給 V3.2。

使用者已批准以下驗收項目延至正式發行後，不代表已通過：
- V3.0 原未實測：真 Email、異機獨立金鑰災復、復原邀請完整真人流程、既有裝置與權限變更、網路中斷降級、公司卡安全套用、實體 UI／業務回歸。
- V3.1 原未實測：兩台 Windows 正向跨機回報、不同 CYID 角色、斷線／撤權、CAS 與稽核操作、100%／125%／150% DPI。
- CI、合成測試和單機本地還原不能代替真人驗收。
以上全部列在發行包內 **發行後待驗收.md**，原始碼唯一清單 docs/POST_RELEASE_ACCEPTANCE.md。歷史人工折讓缺欄位未修復，另列 V3.2。
