CYEnvelope 使用說明（C#／WPF 版，開發測試中）
==========================================

一、開始使用
1. 解壓縮一次，得到 CYEnvelope 資料夾；請保留其中的 Runtime 資料夾。
2. 開啟 CYEnvelope\CYEnvelope.exe。第一次開啟會在同一層建立 Data 資料夾。
3. 從上方「列印設定」選擇 Windows 印表機。
4. 輸入收件人、地址；電話為選填。
5. 核對右側預覽後按「列印信封」。

二、保存時機
按下「列印信封」就代表輸入完成：程式先把聯絡人、地址、電話、郵件種類保存到 Data\CYEnvelope.db，再開啟 Windows 列印對話框。即使取消列印、印表機離線或驅動程式失敗，輸入資料仍已保存。

三、收件人、地址與電話
- 按「列印信封」就是把這筆存進資料庫；下個月輸入客戶名稱的一部分即可找到（例如輸入「高美」，列出名稱含「高美」的客戶，開頭符合的排在前面）。
- 客戶的地址或電話若是這位客戶沒有的新資料，列印時會跳出視窗：可「新增為另一筆」或「覆蓋」上面顯示的那一筆，也可取消。相同地址（台／臺、空白不同視為相同）不會重複詢問。
- 輸入收件人時，下方會列出符合的聯絡人；可用方向鍵及 Enter 選取，或以滑鼠雙擊。
- 選取聯絡人會帶出上次使用的地址、該地址上次使用的電話，以及上次的郵件種類。
- 「已存地址」「已存電話」選單可改選同一聯絡人的其他資料。
- 選取後若再修改收件人姓名，已輸入的地址與電話會保留，但不再視為原聯絡人；要重新開始請按「清空」。
- 修改已存地址或電話後列印，會詢問要覆蓋原資料或另存一筆。

四、郵遞區號
- 只使用三碼。貼上或輸入不含區號的地址，程式立即依離線中華郵政資料判斷並填入；手動修正過的區號，在地址仍屬同一地區時不會被蓋掉。
- 地址欄離開時會再確認一次。
- 無法判斷時不會沿用上一個地址的區號：區號欄清空並加紅框，標籤改為「請手動輸入」，下方狀態列同時提示；請自己填入三碼，填入後紅框消失。不會彈出視窗，也不會擋住列印（區號留空就印空格）。
- 區號會隨地址存進資料庫；下次選到該地址直接帶出。若當時沒有區號，選取時會再判斷一次。
- 先手動輸入區號、再輸入無法判斷的地址時，保留手動輸入的區號。

五、電話格式
可輸入市話、手機、0800 或 +886 開頭號碼，例如：
02-23810435、07-1234567、037-322150、0912-345-678、0800-000-123
分機可輸入「分機 123」「ext.123」「轉123」或「#123」，顯示為 #123。無法辨識的號碼保留原文。

六、郵件種類與方框文字
- 郵件種類（平信、限時、掛號…）可在左側勾選，也可直接點信封預覽左邊的表格對應列（再點一次取消，滑鼠移上去會顯示名稱）；兩種方式同步，任選其一。
- 信封左邊黑框的「內附對帳單」等文字：點預覽上的黑框，從清單選一筆或選「不印方框文字」；「管理清單…」可新增、修改、刪除清單項目。

七、格式與套印
- 15K 預設版面由左至右：收件人（置中於中央框、位於上半部）、電話、地址；地址第一個字比收件人第一個字低 5 mm。位置可在「格式設定」調整。
- 「校正列印」會在普通紙印出各欄位外框、範例文字與毫米刻度，疊在信封上對光檢查；使用與正式列印相同的印表機偏移。
- 內建 15K 標準信封 105 × 222 mm。「格式設定」可新增、複製、刪除自訂格式；內建格式與目前預設格式不可刪除。
- X、Y、寬、高皆為毫米；另可設定字型、字級、直排列數、橫式，以及整體印表機偏移。
- 預覽與實際列印使用同一套繪製。紅線是信封預印底圖，只顯示不列印；實際只印黑字、勾記與方框文字的黑框。
- 文字太長時會自動縮小字級（最多縮到原字級七成，不小於 7 pt）；仍放不下時，列印前會列出超出的欄位並詢問是否繼續。
- 印表機驅動程式不接受信封尺寸時，列印前會提示實際採用的紙張尺寸。

八、輸入方式
「設定」可切換為直接點選信封預覽上的藍色欄位輸入。兩種方式的資料與列印結果相同。

九、列印後自動清空、重印上一筆、清空
- 列印送出成功後，表單會自動清空並回到收件人欄，方便輸入下一筆；方框文字的選擇會保留。取消列印或列印失敗時不會清空。
- 「重印上一筆」（畫面下方）把最近一次列印的收件人、地址、區號、電話、郵件種類與方框文字帶回表單，確認後再自己按「列印信封」。關閉程式後仍可使用。
- 「清空」隨時清除目前輸入，也會把方框文字恢復為清單第一筆。

十、客戶資料管理（「聯絡人資料」）
- 左側搜尋框（有提示文字）輸入客戶名稱的一部分即可篩選；清單顯示各客戶的地址、電話數量。
- 可新增、修改、刪除客戶、地址與電話。修改在複本上進行，按「儲存」才寫入；切換客戶或關閉視窗時若有未儲存的修改，會詢問儲存、放棄或回到編輯。
- 刪除客戶前會列出將刪除的地址與電話數量。修改地址文字時，郵遞區號會依新地址重新判斷（除非你手動改過區號）。

十一、資料備份與損毀
- 程式每天（有客戶資料時）在 Data\Backups 自動保留一份備份，最多 14 份；也可在關閉程式後自行複製整個 Data 資料夾。
- 若開啟時發現資料庫損毀，程式會詢問是否用最近一份備份還原；損毀的檔案會另存為 .damaged-日期，不會刪除。
- 請勿在程式執行時直接修改 CYEnvelope.db。
