# CYERPAutoQuery Project Rules

本文件只記錄 `apps/CYERPAutoQuery/**` 的專案專屬永久規則；共通規則與 Public repository 政策分別以根目錄 `REPOSITORY_RULES.md`、`REPO_POLICY.md` 為準，不在此重複。

## 1. 專案定位

- 正式名稱：`CYERPAutoQuery`；中文顯示名稱為「SMART ERP 自動查詢工具」。
- 目標是以 Windows 桌面自動化，在鼎新 SMART ERP `INVI02` 品號資料建立作業查詢品號並讀取資料。
- 對 ERP 資料**只讀**：只允許開啟查詢條件（F6）、設定查詢條件、按「確定」、切換頁籤與讀取欄位；不得操作新增、修改、刪除、儲存、取消、確認或任何會改變 ERP 資料的功能。
- Windows 發行目標為 x64 portable GUI 程式。

## 2. ERP 操作安全

- 對 SMART ERP 的自動鍵盤操作禁止送出 `Ctrl+A`。
- 開始前必須找到唯一一個 `INVI02` 視窗（標題含「品號資料建立作業」與「INVI02」，排除訊息框）；找不到或多於一個時停止，不得猜測。ERP 同時開著其他作業（例如 COPI08）不影響定位。
- 操作前把 `INVI02` 最大化並帶到前景，以固定幾何操作；不以背景輸入作為正式方案。
- `INVI02` 在新增／修改狀態或有其他對話框時不得開始查詢。
- 每次點擊前確認該點確實屬於目標視窗（未被遮住）；頁籤以「該 TcxTabSheet 變為可見」確認切換成功，查詢結果以表頭品號等於查詢品號確認，不以「看起來點到了」當作成功。
- 頁籤點擊主路徑為已量測的固定幾何位置；點擊後頁籤未顯示時，唯一備援是以 OCR 讀頁籤列找文字再點（使用者 2026-10-16 核准）。不得再疊加其他備援層。
- 操作 ERP 期間鎖定實體滑鼠並在畫面中央顯示「自動查詢中」（同 CYERPAutoInput）；需要使用者處理前先解除。
- 任一自動流程必須支援 `Esc` 緊急停止；停止只中止本程式後續動作，不得替使用者按 ERP「取消」。
- 操作 ERP 期間持有機器層級鎖 `Local\Chihyuan.SmartErp.UiAutomation`，避免與其他 CY ERP 自動化程式同時送出鍵盤滑鼠。

## 3. Public source 與本機資料

- Source、README、測試、workflow 與 Release note 不得包含 ERP 營運資料（價格、成本、庫存、倉別、客戶、人員、公司內部路徑或帳密）。測試只使用假資料，或使用者在需求截圖中示範的單一品號代碼。
- `logs/`、診斷輸出只屬本機資料，不得提交 Git。LOG 預設只記錄長度，不記錄實際品號與欄位內容。

## 4. 共用程式碼

- 介面與 CYERPAutoInput 保持一致（使用者 2026-10-16：未來合併為微服務）。
- Win32 視窗／輸入、滑鼠鎖、中央提示、OCR 與視覺主題目前由 CYERPAutoInput 複製必要部分（使用者 2026-10-16 決定）；複製處需註明來源。兩支程式穩定後應收斂為共用函式庫，屆時移除複本。
