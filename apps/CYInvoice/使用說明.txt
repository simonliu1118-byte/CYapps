一、啟動與資料
1. 本程式適用 Windows 10/11 x64，請直接執行 CYInvoice.exe。
2. 第一次在全新資料夾啟動時，必須先設定管理密碼及 MO店+ Excel 密碼。
3. 設定與發票紀錄存放於 Data；快取與紀錄分別存放於 Cache、Logs。
4. V2.3.0 目前仍使用 Data 內的 JSON 資料檔；請勿刪除或任意修改。搬移程式時，請連同整個 CYInvoice 資料夾一起搬移。

二、環境安全
1. 初次啟動固定使用光貿測試環境，不會開立正式發票。
2. 正式環境需在「設定」輸入公司統編、App Key，並以管理密碼確認。
3. App Key 與 MO店+ 密碼使用 Windows DPAPI 加密，只能由原 Windows 使用者解密。
4. 正式開立前，務必再次確認畫面上方的環境提示。

三、手動開立
1. 選擇一般消費者或公司統編，輸入訂單編號、買方資料與商品明細。自動訂單編號格式為 MYYYYMMDDXXX。
2. 公司統編輸入完整 8 碼後會自動查詢買方名稱：先查本機人工記憶，再查光貿 API。若人工修改後與 API 名稱不同，買方名稱會以紅字提示，欄位右側會出現可點擊的 ↻ 供強制重新查詢 API。
3. 公司統編發票可切換含稅／未稅輸入；已有明細會自動換算到小數點後最多 7 位。
4. 品名按 Enter 移到數量，數量按 Enter 移到單價；單價按 Enter 後，會移至既有下一列品名，若目前是最後一列則自動新增明細並移到新品名。
5. 使用「預覽」核對內容，再按「開立測試發票」或「開立正式發票」。
6. 同一來源、同一原始訂單編號成功開立或結果不明後，程式會阻擋重送，避免重複開票。

四、Excel 匯入
1. MO店+、酷澎及鼎新 ERP 都會先開啟同一套開立發票匯入確認視窗；只有原始 Excel 表頭與取用欄位依平台不同。
2. 請逐張核對並勾選；取消、未勾選、資料有問題或尚未完成確認的訂單不會送出。
3. MO店+ 使用設定內保存的 Excel 密碼唯讀解析；酷澎依已寄出 DeliveryList 欄位解析。
4. 鼎新 ERP 可直接匯入 .xlsx。活頁簿必須包含「單頭資料」與「單身資料」，且一個檔案只允許一張銷貨單：
   - 單頭使用銷貨單號、統一編號、客戶全名、本幣合計。
   - 單身使用品名、數量、金額；若有「單位」欄會一併傳送至光貿。
   - 金額是權威值，單價由金額 ÷ 數量推導；單身金額合計必須與單頭本幣合計一致。
5. 鼎新確認畫面可修正統一編號及買方名稱。完整 8 碼統編會使用與手動開票相同的自動查詢；修改後必須按「套用資料」才可開立。畫面會保留原始鼎新買方資料供核對。
6. 光貿測試環境送出時會保留原始 OrderId 供防重與核對；客戶、商品、聯絡資料及備註會去識別化，本機確認畫面及紀錄仍保留原始內容。
7. 匯入確認的「檢查狀態」會直接顯示是否可開立；已有開立紀錄或結果不明時會禁止重送。

五、已開立發票清單
1. 預設查詢本月第一日至今天，可再依發票號碼、訂單、買受人、統編、來源與狀態篩選；來源包含手動、MO店+、酷澎及鼎新 ERP 等現行來源。
2. 「重新整理狀態」會向光貿查詢，不會改寫原送出時間，也不會自動重送結果不明的發票；按鈕右側會顯示「單擊發票號碼即可複製」。單擊清單中的發票號碼欄位會直接複製該號碼，並短暫顯示「✓ 已複製 XXXXXXXX」。
3. 紙本與會員載具的詳細資訊視窗使用一致的精簡配置。紙本會顯示官方 A4 第一頁預覽；會員載具使用模擬電子發票與本機交易明細，不呼叫紙本 PDF API。
4. 「檢視 PDF」沿用 Edge PDF Viewer：一般消費者直接開啟完整 A4；公司統編會先顯示 A4 整張、A4（地址＋A5）、A4（A5 內容）、A5 或 QRcode_A4 五張示意卡片，選擇後才開啟對應的真實 PDF。A5 示意與直接列印均為橫式 210×148；縮圖中的白底即紙張本身，因此 A5 白底只佔 A4 高度約一半並位於上方。QRcode_A4 的票面區塊位於接近左上方，但不貼邊。
5. 「列印發票」會取得同一份官方 PDF 後直接送到 CYInvoice 記住的發票印表機，不開啟可見 PDF Viewer。直接列印只允許 Windows 回報支援雙面的印表機；選擇視窗只列出這些印表機。若要使用未回報雙面能力的印表機，請改用「檢視 PDF」後由 PDF Viewer 手動列印。
6. 一般消費者紙本固定以 A4、雙面、長邊翻轉直接列印；此設定只作用於 CYInvoice 當次列印，不修改 Windows 全域預設印表機。記住的印表機若不存在或不再回報雙面能力，程式會要求重新選擇，不會改送 Windows 預設印表機。
7. 公司統編使用「列印發票」時同樣先選五種官方版型，再直接送至記住的雙面印表機；公司列印沿用該印表機的 duplex 預設。
8. PDF 檢視視窗使用 Edge PDF Viewer 右上方原生工具列縮放、下載及手動列印。若畫面無法啟動，請確認 Windows 已安裝 Microsoft Edge WebView2 Runtime。
9. 會員載具沒有一般紙本 PDF；模擬票會明確標示非正式憑證；其一維條碼及兩個 QR Code 只固定連至光貿電子發票網站，不承載正式發票驗證資料。

六、問題排查
1. 上方 API 狀態：灰色為查詢中、綠色為正常、紅色為異常。
2. 發生問題時請保留完整 CYInvoice 資料夾及 Logs，並先備份 Data。
3. 若下載正式 GitHub Release，請同時核對附帶的 SHA-256；Public 可下載不代表開放原始碼，授權仍以 LICENSE 為準。
4. 測試 Artifact 依套件內 `Channel: engineering` 中繼資料及 Artifact 名稱與正式包區分；版本標題不另加「工程測試包」。未經明確發布要求的版本不建立正式 Release。
