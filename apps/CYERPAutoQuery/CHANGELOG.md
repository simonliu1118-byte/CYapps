## V1.1.0（2026/10/27，工程驗證，尚未正式發行）

升 Y：新增 CY Web 遠端關閉 ERP 的能力（使用者 2026-10-27）。需 CY Web 0.9.38 起。
- CY Web「關閉 ERP」：每次領工作時一併讀取 CY Web 的要求；**佇列跑完（沒有工作）才處理**。「立即關閉」用與閒置關閉相同的方式關閉 ERP（ERP 詢問未存檔內容時保留不關，回報 KEPT_OPEN）；「強制關閉」結束擁有 ERP 視窗、同一 Windows 工作階段的程式（先送關閉訊息，5 秒後才終止）。結果回報 CY Web（CLOSED／KEPT_OPEN／NOT_OPEN／FAILED）；程式忙碌時不回報，下次領工作再處理。
- CY Web 暫停期間（15／30／60 分鐘）不自動開啟 ERP。
- ERP 閒置登出授權（使用者截圖 2026-10-27）：「使用者因閒置而登出授權，請問是否重新登入授權?」按 Yes；「…無法開啟作業程式!」按 OK。每次查詢前先檢查並回答；查詢途中失敗時若有這類訊息，回答後重新查一次。其間出現「人數已滿」則按 OK 並回報 ERP_SEATS_FULL。

## V1.0.0 — 2026/10/21（正式 Release：tag `cyerp-auto-query-v1.0.0`）

1.0 正式版（使用者 2026-10-21 指示發布），彙整 V0.10.2 Build 1–4：
- 進貨輔助（CY Web 類型 `RESTOCK`）：單據日期起訖（必填、最多 31 天）內全部客戶的銷貨單（COPR15）與銷退單（COPR16），依品號與日期加總銷貨／銷退數量（含贈／備品量，另附贈品部分），查詢中回報進度給 CY Web。

- 自本版起：自動更新顯示下載提示條、閒置 10 秒倒數、「正在更新」視窗；複製失敗會還原並照常開啟，提示後 8 小時再試（V0.10.0 Build 2 起的程式更新到本版時即可看到）。
