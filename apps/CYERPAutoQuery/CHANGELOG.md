# CYERPAutoQuery Changelog

## V0.1.0

- Build 2（2026/10/16）：查詢結果只保留使用者指定的欄位（`ItemFieldCatalog`，本機畫面與之後 Web 白名單共用）：品號、品名、規格、單位、庫存數量、商品分類（ERP「商品」＋料件分類三名稱）、商品描述、條碼編號、批號管理、有效天數、主供應商（＋名稱）、標準進價、標準售價、售價定價一～六；庫別：庫別、庫別名稱、儲位、安全存量、經濟批量、上次盤點日、最近入庫日、最近出庫日。其他匯出欄位（成本、庫存金額等）解析後即丟棄；匯出缺少清單欄位時停止並列出缺少的欄位。
- Build 1（2026/10/16）：資料改由 ERP「轉出至 Excel」取得（使用者發現匯出更乾淨、不會錯）：查到品號後切到「基本資料1」→ Ribbon「Excel」→「轉出至 Excel」→ 單頭與單身各按「全選」→ 儲存檔案填入程式旁的 `TEMP` 資料夾 → 確定 →「檢視Excel資料?」按 No → 讀取單頭資料（約 150 個具名欄位）與單身資料（庫別）後立即刪除檔案。不再逐頁籤讀取畫面欄位；主視窗改列「欄位／內容」與庫別表。Ribbon 與選單以 OCR 找文字（同 CYERPAutoInput 的列印）。
- Build 0（2026/10/16）：初版。輸入品號 → 找到唯一的 ERP「品號資料建立作業 (INVI02)」並最大化 → F6 開啟「設定查詢條件」→ 切到「一般選項」→ 品號條件設為「=」並輸入品號 → 確定 → 核對表頭品號 → 依序點「基本資料1」「基本資料2」「採購生管1」「售價」讀取欄位 → 在主視窗列出表頭與明細（可複製到 Excel）。查無品號（ERP 轉到資料瀏覽、表頭空白）時顯示「查無此品號」。介面比照 CYERPAutoInput（工具列＋ERP 狀態標籤＋群組＋狀態列）；查詢期間鎖定實體滑鼠、畫面中央顯示「自動查詢中」。頁籤以固定座標點擊、未切換時改用 OCR 找頁籤文字；查詢中可按 Esc 中止。
