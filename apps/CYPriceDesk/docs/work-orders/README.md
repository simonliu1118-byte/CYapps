# CYPriceDesk 工作單

工作單描述需求、範圍與驗收，不是規則來源；規則仍以 `REPOSITORY_RULES.md`、`REPO_POLICY.md`、本專案 `PROJECT_RULES.md` 為準。一個版本一張，檔名 `WO-<版本>.md`，格式同 `apps/CYERPAutoQuery/docs/work-orders/README.md`（背景、已定案事項、範圍、不做、實作指引、驗收清單、完成報告、審查紀錄）。

## 整合路線（使用者 2026-11-16 定案）

把手動查價與自動查價整合為一個站：使用者設定要追蹤的商品（例如自己在蝦皮上架的商品），系統定期用該商品自動查價，把結果作為調整定價的依據。

| 階段 | 工作單 | 內容 |
| --- | --- | --- |
| 1 | `WO-1.1.0.md` | 手動查價原型搬到 Cloudflare Worker＋D1＋CYID；價格紀錄全站一份、有使用權者皆可查價與編輯、所有寫入留 audit |
| 2 | `WO-1.2.0.md` | 自動查價：sandbox `ScraplingProbe` 的 Python 抓價程式（momo、飛比蝦皮、飛比酷澎）移入本專案 `fetcher/`，部署於 Vercel，只接受 Worker 簽章請求；Worker 端查詢畫面、規格分類（D1）、查到的結果一鍵加入價格紀錄 |
| 3 | `WO-1.3.0.md` | 追蹤商品：設定自己的商品、售價與各來源查詢條件；Cron 定期查價、保存每次結果、同規格比較與定價參考 |
| 4 | `WO-1.4.0.md` | 介面改版：統一查價、三平台售價比價、單張多線走勢圖、待確認佇列、手動比價（取代比價總覽與手動價格紀錄） |

三個階段合併於 CYapps #621（2026-11-16，原 #619、#620 併入）；首次上線先不設定抓價服務，自動查價與排程待 Vercel fetcher 設定後啟用。

sandbox 的 `ScraplingProbe` 原型：PR #31 已於 2026-11-17 關閉（未合併，sandbox `main` 不含此專案）；兩個原型分支與 Vercel 舊原型專案已由使用者於 2026-11-18 刪除。
