CYInvoice V3.0.0 版本內容

本版範圍
- 支援單機 Local 與 CYID Cloud；新版不提供 Built-in／Self-hosted 現役模式。
- CYID 公司卡：超管管理公司統編、App Key 與 MO店+ 密碼；各授權 Windows 經超管明確確認後才套用本機，仍使用 DPAPI 保護，不自動覆寫其他電腦。
- 裝置災難復原：CYWEB 超管重新驗證後簽發短效邀請；新機確認原公司並保存 Pending Token，再明確確認接管。成功後才撤銷同公司所有其他舊裝置；舊安裝再次連線時可能依撤銷流程清除本機資料。
- 遺失回覆保留同一 Pending Token 與 scope，先讀回原結果，不自動重簽、重建 Token 或重送發票。
- 修正復原密碼對合法 Unicode 字元的相容性。
- 保留既有手動／MO／酷澎／鼎新匯入、查詢、作廢、人工折讓、PDF、同步與防重複處理。

升級與使用
- 升級前自行備妥完整原資料夾；解壓程式後保留原 Data，不借用其他電腦的 Token 或 DPAPI 設定。
- 雲端須先由維運完成 CYID、相容 Worker、schema 15 及對應功能設定；安裝 Windows 程式不會自動遷移 D1 或建立雲端資源。
- 舊 Built-in／Self-hosted 安裝不要直接以本版進行雲端轉換；先保留原版本與資料，再由維運確認接續方式。
- 公司卡的「已設定」只代表雲端狀態，各電腦仍須在「設定 → CYID 公司卡」由超管授權套用。
- 一般新增裝置沿用配對／邀請；災難復原是全公司裝置接管，不能當一般新增裝置使用。

驗收與已知限制
- 本次依隔離與合成驗收放行，Windows 虛擬機、Cloud 與 CYWEB 的相關測試已通過；測試沒有操作正式 CYID 或公司資料。
- 真實 Email 送達、真正實體雙機操作、獨立保管金鑰的實際異機完整還原尚未實測，不能把本版發布當作這些驗收已完成。
- 裝置復原不會重建整個雲端服務或遺失的本機未上雲資料；DPAPI 設定仍受原 Windows 使用者限制。Local／單機資料由裝置使用者自行負責保管，不新增常態災難備份。
- 人工折讓逐筆申請／處理歷史與結案狀態的既有缺欄位，本版未修復。Work Item／跨機審核、正式折讓 API 與後續項目留待 3.1／3.2／3.3，本次不合併 PR #440 或後續功能。

本版不建立或修改正式 CYID 資料，不因發行自動簽發或兌換復原碼。使用任何復原接管前，須再次確認其影響與當次授權。
