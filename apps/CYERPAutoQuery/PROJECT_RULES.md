# CYERPAutoQuery Project Rules

本文件只記錄 `apps/CYERPAutoQuery/**` 的專案專屬永久規則；共通規則與 Public repository 政策分別以根目錄 `REPOSITORY_RULES.md`、`REPO_POLICY.md` 為準，不在此重複。

## 1. 專案定位

- 正式名稱：`CYERPAutoQuery`；中文顯示名稱為「SMART ERP 自動查詢工具」。
- 目標是以 Windows 桌面自動化，在鼎新 SMART ERP `INVI02` 品號資料建立作業查詢品號並讀取資料；批號管理的品號另從 `INVQ01` 庫存狀況查詢作業讀取各批庫存量，使用者要求時再讀取歷史異動（使用者 2026-10-16）；客戶資料讀自 `COPI01`，供應廠商資料讀自 `PURI01`，廠商的進貨單與退貨單讀自 `PURR18` 進貨單明細表與 `PURR22` 退貨單明細表，客戶的銷貨單與銷退單讀自 `COPR15` 銷貨單明細表與 `COPR16` 銷退單明細表，未收款讀自 `ACRR18` 未結案應收明細表（使用者 2026-10-16／17）。
- 對 ERP 資料**只讀**：只允許開啟查詢條件（F6）、設定查詢條件、按「確定」／「開始查詢」、切換頁籤、「串查」開啟 INVQ01、「轉出至 Excel」／「轉出到Excel」、報表的「即時報表」與報表視窗的 XLSX 匯出，以及讀取；不得操作新增、修改、刪除、儲存、取消、確認或任何會改變 ERP 資料的功能。
- Windows 發行目標為 x64 portable GUI 程式。

## 2. ERP 操作安全

- 對 SMART ERP 的自動鍵盤操作禁止送出 `Ctrl+A`。
- `INVI02` 視窗以標題（含「品號資料建立作業」與「INVI02」，排除訊息框）辨識；ERP 同時開著其他作業（例如 COPI08）不影響定位。多個 INVI02 時只用處於檢視狀態的那個（最上層者優先），都不在檢視狀態則停止。沒有 INVI02 時，只可從 ERP 主視窗的「作業速查」輸入 INVI02 開啟，輸入內容須讀回確認才按 Enter（使用者 2026-10-16）。
- 操作前把 `INVI02` 最大化並帶到前景，以固定幾何操作；不以背景輸入作為正式方案。
- `INVI02` 在新增／修改狀態或有其他對話框時不得開始查詢。
- 品號（以及客戶、廠商、業務員代號）只接受 1～40 個英文字母、數字與「-」，第一個字須為英文字母或數字（使用者 2026-10-21：如 K1807003-1）；不接受空白、其他符號、全形或中文。品號比對區分大小寫（使用者 2026-10-16）。
- `INVQ01` 只從 INVI02 的「串查」→「庫存狀況查詢作業」（兩個同名項目取最上面的）開啟，須確認帶出的品號與查詢品號完全相同；查詢條件只設頁籤與歷史異動起迄日（讀回確認），本機未勾選日期時不向 ERP 輸入該欄，保持 ERP 自行處理；CY Web 負責補齊完整起迄日再交給 Agent，不由 Agent 預設最近一年；起迄範圍不設上限，範圍限制由 CY Web 的查詢模組負責（使用者 2026-10-16：AUTO 只提供開放的查詢功能）。用完一律以關閉視窗訊息關閉（失敗或 Esc 後亦同），不留給使用者（使用者 2026-10-16）。
- 品名查詢只可在「設定查詢條件」的「進階設定」貼上程式產生的固定條件 `(INVMB.MB002 like N'%關鍵字%')`：欄位固定寫在程式（不放設定檔）；關鍵字 1～40 字，拒收 `' % _ [ ]` 與控制字元；貼上後須讀回一致。結果從「資料瀏覽」轉出，每筆品名都必須含關鍵字，否則視為條件未套用而不採用。品號查詢前若進階設定留有條件，先按「清除」；品名查詢前清空一般選項的品號（使用者 2026-10-16）。
- 客戶查詢使用 `COPI01` 客戶資料建立作業，定位、只讀與轉出規則同 INVI02（使用者 2026-10-16）：客戶代號走一般選項「=」→「基本資料」頁籤轉出；客戶名稱只可在進階設定貼上程式固定產生的 `(COPMA.MA002 like N'%關鍵字%') OR (COPMA.MA003 like N'%關鍵字%')`（簡稱或全名一律同時查），從資料瀏覽「轉出全部符合查詢條件的資料」，每筆的簡稱或全名必須含關鍵字，否則不採用。客戶代號規則同品號。
- 供應廠商查詢使用 `PURI01` 供應廠商資料建立作業，流程與規則同 COPI01（使用者 2026-10-17）：廠商代號走一般選項「=」→「基本資料」頁籤轉出；廠商名稱只可在進階設定貼上程式固定產生的 `(PURMA.MA002 like N'%關鍵字%') OR (PURMA.MA003 like N'%關鍵字%')`（簡稱或公司全名一律同時查），每筆的簡稱或公司全名必須含關鍵字，否則不採用。廠商代號規則同品號。簡稱讀「簡稱」欄（匯出的「廠商簡稱」是總公司的）。
- 進貨退貨單查詢（使用者 2026-10-18）：`PURR18` 流程同 COPR15，只設廠商代號（起＝迄）、單據日期與進階選項確認狀態／結帳狀態「全部」；進貨單號、進貨庫別須為空，選擇日期須為單據日，「僅列印…」不可勾，否則停止。`PURR22` 沒有廠商條件，只設相同單據日期，退貨單號須為空，整份轉出後只保留該廠商；每列須在日期內、小計須等於讀到的全部退貨單，否則不採用。報表與檔案處理同 COPR15。
- ERP 自動登入與閒置關閉（使用者 2026-10-19）：「ERP 登入」設定保存 ERP 程式路徑、帳號、密碼（Windows DPAPI 加密，只存在本機 `config/erp.json`，不寫入 LOG）、登入公司與兩個閒置分鐘。查詢找不到 ERP 主視窗時，自動開啟 ERP 並登入：只在 ERP 程式行程中、第二格是密碼框的登入畫面輸入；帳號 → Enter → 密碼，公司清單空白時依使用者流程清空後帳號 → Enter → 密碼 → Enter 觸發錯誤，再輸入一次帳號密碼；選設定的公司後按登入。ERP 主視窗或建立作業沒有回應（5 秒內不回應視窗訊息）、作業速查開啟程式逾時，且已設定自動登入時，強制關閉 ERP、重開登入並重試一次。強制關閉只針對**擁有 ERP 主視窗或建立作業視窗、且與本程式同一 Windows 工作階段**的行程（使用者 2026-10-26）：不以程式名稱、資料夾或行程樹挑選，不碰沒有 ERP 視窗的行程（ERP 伺服器上的 SMDispatcher、SMCounterS、AUC 等服務），不碰其他工作階段；先對其 ERP 視窗送關閉訊息，5 秒未結束才終止該行程（不含子行程），建立作業的行程先、主視窗的行程最後。品號／客戶／廠商資料建立作業預設閒置 10 分鐘、ERP 預設閒置 30 分鐘關閉，閒置以最後一次查詢與本機最後鍵盤滑鼠操作較晚者起算；關閉只送視窗訊息，作業詢問（例如編輯中）時取消並保留；ERP 離開確認只在有「是／確定／OK」按鈕時按下，其他情況保留 ERP 並記錄。可設定開機自動開啟本程式（目前 Windows 使用者的 Run 機碼）。
- ERP 授權訊息（使用者 2026-10-27）：登入後「人數已滿」按 OK（ERP 隨即自行關閉），查詢停止並回報 `ERP_SEATS_FULL`；「使用者因閒置而登出授權，請問是否重新登入授權?」按 Yes，「…無法開啟作業程式!」按 OK。這些訊息可能屬於「Leader作業元件中心」而非 MainMenu，以訊息內容辨識；每次查詢前先回答，查詢途中因此失敗時回答後重查一次。其他未知訊息仍照原規則停止並顯示。
- 銷貨單查詢使用 `COPR15` 與 `COPR16`（使用者 2026-10-16／17，兩者流程相同），只從作業速查開啟：基本選項「選擇客戶代號」起迄都填同一客戶代號（貼上並讀回）、「選擇單據日期」比照 INVQ01 日期輸入（未指定的日期欄若已有值即停止）；進階選項確認狀態與結帳狀態設為「全部」並讀回，「列印單價金額」須維持勾選（轉出缺單價欄即不採用）；只按「即時報表」，報表視窗按 XLSX、選「顯示數值欄位無千分符號」、按「確認」。ERP 固定寫入 `C:\My Documents`，程式先建立該資料夾，「匯出失敗…找不到指定的路徑」時建立後重做一次；匯出檔立即移到 `TEMP`，讀完即刪，不留在 ERP 資料夾。每列客戶代號須等於查詢代號、單據日期須在範圍內，否則不採用。查詢前關閉留著的報表視窗，用完關閉報表視窗與條件視窗（失敗或 Esc 後亦同）。
- 單筆銷貨／銷退單（未收款憑證，使用者 2026-10-17）：單別 23 開頭用 COPR15、24 開頭用 COPR16，其他單號不查。基本選項「選擇銷貨單號」（「選擇銷退單號」）起、迄各自點選後按 Home、貼上不含「-」的單號並讀回，客戶與單據日期群組必須是空的；其餘同銷貨單查詢，轉出每列單號須等於查詢單號。
- 未收款查詢使用 `ACRR18` 未結案應收明細表（使用者 2026-10-17），開啟、即時報表、XLSX 匯出、檔案搬移與視窗關閉同 COPR15。可查單一客戶、單一業務員或全部：單一時勾選該群組的「區間選擇」（以起迄欄位出現確認），起迄貼上同一代號並讀回，另一群組必須是空的；全部時客戶與業務員群組都必須是空的（有殘留條件即停止）。帳款截止日期維持 ERP 預設。轉出每列的客戶（或業務員）代號須等於查詢代號，各結帳單未收帳款加總須等於報表「合計」，否則不採用。
- 進貨輔助（CY Web 類型 `RESTOCK`，使用者 2026-10-20／21）只由 CY Web 送出，單據日期起訖必填、最多 31 天。COPR15／COPR16 依銷貨單查詢流程執行，但客戶代號起訖清空（讀回確認為空）代表全部客戶，轉出不核對客戶代號；依品號、日期加總銷貨與銷退數量（含贈／備品量，另附其中的贈品部分）。庫存只以 INVI02 批次查：在進階設定貼上程式固定產生、以 OR 連接的 `(INVMB.MB001 = N'品號')` 條件（與品名查詢共用同一段進階設定流程），從資料瀏覽「轉出全部」讀庫存數量，不開 INVQ01。每批最多 100 個品號；條件框字數上限（EM_GETLIMITTEXT）放不下或貼上後讀回不一致時，該批減半重試；最多 500 個品號，連續 3 批失敗即停查其餘並回報原因。查詢中可回報進度給 CY Web（至多每 2 秒一次），回報失敗不影響查詢。
- ERP 每個動作（確定、開始查詢、切頁籤、開啟作業、轉出）之後，ERP 需要時間重建畫面；之後任何讀取（找頁籤、找控制項、讀表頭、找視窗）都必須用有上限的輪詢等待到條件成立，不得只看一次就判定失敗（使用者 2026-10-16：多次因太早讀取而失敗）。
- 每次點擊前確認該點確實屬於目標視窗（未被遮住）；頁籤以「該 TcxTabSheet 變為可見」確認切換成功，查詢結果以表頭品號等於查詢品號確認，不以「看起來點到了」當作成功。
- 品號資料以 ERP「轉出至 Excel」取得（使用者 2026-10-16）。匯出前在匯出設定的「單頭」「單身」各按「全選」，不依賴別人留下的勾選。匯出檔只寫入程式旁的 `TEMP` 資料夾、每次新檔名，讀完立即刪除；「檢視Excel資料?」一律回答 No。INVQ01 的「轉出到Excel」同樣規則。
- 成本與金額欄位（INVI02 單位成本、庫存金額；INVQ01 單位成本、異動金額、庫存成本等）解析後即丟棄，不顯示、不送出。「標準進價」本機可顯示，送往 CY Web 只在工作帶 `includeCost:true`（該員工有 CY Web「ERP 商品成本」權限）時才送出（使用者 2026-10-17）。
- Ribbon 與其下拉選單以 OCR 找文字點擊，不用固定座標（點錯可能觸發其他功能）。
- 頁籤點擊主路徑為已量測的固定幾何位置；點擊後頁籤未顯示時，唯一備援是以 OCR 讀頁籤列找文字再點（使用者 2026-10-16 核准）。不得再疊加其他備援層。
- 操作 ERP 期間鎖定實體滑鼠並在畫面中央顯示「自動查詢中」（同 CYERPAutoInput）；需要使用者處理前先解除。
- 任一自動流程必須支援 `Esc` 緊急停止；停止只中止本程式後續動作，不得替使用者按 ERP「取消」。
- 操作 ERP 期間持有機器層級鎖 `Local\Chihyuan.SmartErp.UiAutomation`，避免與其他 CY ERP 自動化程式同時送出鍵盤滑鼠。

## 3. 自動更新與正式 Release

- 比照 CYERPAutoInput（使用者 2026-10-17）：程式只認本專案的正式 GitHub Release（tag `cyerp-auto-query-vX.Y.Z`，非 draft／pre-release，附 `CYERPAutoQuery_VX.Y.Z.zip` 與 `.sha256`）；Actions 測試包不算。啟動後與每 4 小時檢查一次，只有更高的 X.Y.Z 才更新；下載後核對 SHA-256，沒有查詢進行中、也沒有其他視窗時自動套用並重新開啟，否則在關閉程式時套用。`config`、`TEMP`、`logs` 不在套件內，更新後保留。
- 正式 Release 只由 `main` 手動啟動 `CYERPAutoQuery Release` workflow，`BUILD` 必須為 0、CHANGELOG 須有該版摘要，tag 不覆寫。

- 更新過程須讓電腦前的人看得到（使用者 2026-10-20，與 CYERPAutoInput 相同）：下載與等待時主視窗顯示提示條；閒置時置頂倒數 10 秒，可「立即更新」或「稍後再更新」（延後 30 分鐘），倒數中開始工作即取消。套用時先備份會被覆蓋的檔案，複製失敗就還原備份；無論成功或失敗都重新開啟程式，失敗時提示可能需要手動更新，8 小時後再自動嘗試。

## 4. Agent 與 CY Web 分工

- 本程式是 ERP 與 CY Web 之間的中介層（使用者 2026-10-17）：只負責把 ERP 資料正確取出、驗證（查詢條件確實套用、欄位齊全）並整理成結構化資料；查詢範圍限制、資料之間的關聯與呈現（例如銷退單連到原銷貨單、排序分組）、業務規則交給 CY Web。
- 之後做任何功能時，若判斷某部分放在 CY Web 處理更好，必須主動告知使用者並說明理由，由使用者決定（使用者 2026-10-17）。

- CY Web 關閉／暫停 ERP（使用者 2026-10-27）：CY Web 有 ERP 查詢權限的成員可要求關閉 ERP（立即，或暫停 15／30／60 分鐘）或強制關閉。本程式在 claim 時讀取要求，**沒有待處理工作時**才執行：關閉同閒置關閉（只送視窗訊息，ERP 詢問未存檔內容時保留）；強制關閉同上方強制重開的行程挑選規則，但不重新開啟。結果回報 CY Web。暫停期間不自動開啟 ERP；新查詢由 CY Web 直接擋下並顯示下次可查詢時間。

## 5. Public source 與本機資料

- Source、README、測試、workflow 與 Release note 不得包含 ERP 營運資料（價格、成本、庫存、倉別、客戶、人員、公司內部路徑或帳密）。測試只使用假資料，或使用者在需求截圖中示範的單一品號代碼。
- `logs/`、`TEMP/`（ERP 匯出檔，含成本與庫存金額）、診斷輸出只屬本機資料，不得提交 Git；測試只用程式產生的假匯出檔，不得提交真實匯出檔。LOG 預設只記錄長度，不記錄實際品號與欄位內容。

## 6. 共用程式碼

- 介面與 CYERPAutoInput 保持一致（使用者 2026-10-16：未來合併為微服務）。
- Win32 視窗／輸入、滑鼠鎖、中央提示、OCR 與視覺主題目前由 CYERPAutoInput 複製必要部分（使用者 2026-10-16 決定）；複製處需註明來源。兩支程式穩定後應收斂為共用函式庫，屆時移除複本。
