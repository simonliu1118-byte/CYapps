# CYERPAutoInput 版本紀錄

本檔保存可確認的歷史事實。所有版本皆為工程測試版，未正式 Release。C# 重寫線（V0.1.0 起）於 2026-10-11 以 PR #104 squash merge 進 `main`（V0.2.0 Build 31），取代舊 Go 線 `V0.0.10 Build 19`。實機結果以 `WORK_HANDOFF.md` §4 為準。

## V0.2.1 — 2026/10/11（工程測試中，未正式 Release）

- Build 2（2026/10/11）：蝦皮截圖視窗開啟時自動擷取：找到開著蝦皮訂單頁的瀏覽器（標題含 Shopee／蝦皮，否則最上層的 Chrome／Edge／Firefox），CY 視窗暫時隱藏、忽略實體滑鼠，先捲到頂端再一段段往下捲並截圖；每次捲動的距離由畫面像素比對量出（不受瀏覽器縮放與捲動速度影響，固定在上方的瀏覽器列與蝦皮頁首自動排除），重疊部分只取一次；讀到「買家總支付金額」或捲到底即停，再依卡片標題切出「訂單編號～共 N 個商品」「商品表（表頭～隱藏入帳明細）」「買家實付金額～買家總支付金額」三段交給原本的解析（含缺格重讀）。Esc 停止。截圖視窗開啟後由使用者按「開始」；擷取與判讀都沒問題時自動帶回表單，有問題就提示並暫停，改用「框選截圖」補圖（也接受 Win+Shift+S 截圖後 Ctrl+V 貼上），再按「帶入表單」照原流程。設定新增「蝦皮全自動」（只限蝦皮；MO店+、酷澎要補發票資料）：按「開始」後一路擷取、判讀、帶回、輸入 ERP、儲存並列印（不論自動儲存／列印設定）；中途改手動補圖時，按「帶入表單」後一樣繼續全自動，帶回時若有待確認項目先詢問，預設停止。OCR 把「包裹」讀成「包裏」時也能找到物流方式。

- Build 1（2026/10/11）：蝦皮截圖視窗開啟後自動進入 CY 自己的框選截圖：CY 視窗暫時隱藏、畫面凍結變暗，拖曳框選後放開即加入並在背景辨識，接著自動開下一張；按 Esc（或右鍵）結束並回到截圖視窗，可再按右上角「截圖」繼續。截圖卡片的「移除」改為圖片右上角的紅底白字圓形 ×；結束框選後仍可用 Windows 內建截圖＋Ctrl+V 補圖。自動列印考慮儲存後 ERP 仍在處理：「列印 → 直接列印」整段重試（每次間隔約 0.8 秒、最多 20 秒），直到真的點到「直接列印」；選單沒出現時只在 ERP 有彈出視窗時才按 Esc 關閉。

- Build 0（2026/10/11）：自動列印實測「Ribbon 上找不到『列印』」（V0.2.0 Build 31）：放寬比對，OCR 把「列印」與相鄰文字黏在一起或第二個字讀錯時也能找到並只點這兩個字；選單只要讀到「直接」即可；每次把 Ribbon 讀到的文字與位置寫進 LOG，選單找不到時也記錄（實機 LOG：這台的 OCR 把 Ribbon 逐字回傳，「列」「印」是兩個框，改為同一行相鄰的字先串起來再找）。單據已儲存就自動清空表單（即使有待確認項目或未列印，提醒視窗照常顯示）；未儲存時仍只在沒有待確認項目時清空。蝦皮截圖視窗的「截圖說明」改名「說明」，移到右上角。蝦皮截圖明細（依實機 LOG）：編號「1」「2」都可能被讀成「-」，改為以同張讀得清楚的編號依序推算（編號由上往下連號）；同一格編號的重複框只留一個；劃線原價讀成比小計還小（480 讀成 180）時視為讀錯，改用商品合計。
