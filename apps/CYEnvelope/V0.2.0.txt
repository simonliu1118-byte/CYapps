CYEnvelope V0.2.0（開發中，尚未發行）
日期：2026/09/27
BUILD：0

階段一：C#／WPF 重做基礎
- 建立全新 SQLite 資料模型，不遷移尚未上線使用的 Go 版測試資料。
- 保存聯絡人多地址、多電話、各地址上次使用電話與上次郵件種類的資料欄位。
- 匯入 368 筆離線三碼郵遞區號資料，無法辨識時回傳空值供介面保留原碼。
- 建立毫米座標的共用信封繪製器；預覽顯示紅色套版參考，列印內容只繪黑字、勾記與黑色方框／直排文字。
- 匯入 AITeam 正式 ENV SVG／ICO 資產。
- 建立 Windows 核心檢查程式，涵蓋郵遞區號、電話格式、SQLite 多地址／多電話保存及繪製器輸出。

驗證狀態
- Linux 上以 .NET 10 SDK + EnableWindowsTargeting 編譯專案和測試程式成功。
- 尚未在 Windows 執行測試程式，也未完成介面、列印連接、打包及實機試印。
- Go 版仍保留作行為對照。此版本尚無 C# 測試包與正式 Release。

階段二初版（待 Windows 驗證）
- 主畫面加入收件人候選清單、地址、電話、郵遞區號、郵件種類和即時預覽。
- 地址離焦時重新判斷郵遞區號；無法辨識時保留原有內容。
- 聯絡人管理加入多地址、多電話及備註；格式設定同時繪製所有欄位，選取者高亮，儲存與設為預設分開。
- 接上原生列印對話框；按列印先保存，再送出沒有預印紅線的共用繪製結果。
- 加入直接點選預覽欄位後以浮動輸入框輸入的版型，並提供收件人候選清單；此互動尚待 Windows 使用者操作驗收。
- 橫式切換一併旋轉各欄位、郵件種類座標並交換信封長寬；直排黑框保持直向。
- 列印位置尚未在實際 15K 信封與目標印表機校正。
- CI 改由 Windows 建置 C# 程式、執行核心檢查與啟動檢查；工程包要待封裝與掃描通過後另行產出。

封裝依賴：多檔自包含包目前受共用安全掃描器誤判阻擋；治理修正獨立於 CYEnvelope 分支，通過並合併後才啟用公開 Artifact。
- 已加入 build-csharp.ps1，供 Windows 重建自包含多檔 ZIP、執行掃描及計算 SHA-256；正式 CI 的 Artifact 步驟仍等待治理掃描器更新後接入。
