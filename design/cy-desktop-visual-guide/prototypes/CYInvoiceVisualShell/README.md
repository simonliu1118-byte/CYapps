# CYInvoice Visual Shell Prototype

此目錄是 `CY Desktop Visual Guide` Phase 1 的 **WinForms 真機視覺驗證殼**，不是正式 CYInvoice 產品線。

- 不連 AMEGO API。
- 不讀寫正式 CYInvoice database / settings。
- 不開立、查詢、作廢或同步任何真實發票。
- 所有表格內容均為假資料，只存在記憶體。
- 使用現行 CYInvoice icon 作為既有完成資產的引用；不修改該 icon。
- Theme 可切換 Blue / Teal / Coral / Apricot。
- Density 可切換 Compact / Standard / Comfortable。
- 用來驗證 Typography、Control size、Spacing、Table、Dialog、Status 與 100% / 125% / 150% DPI。

此 prototype 與 `CY_DESKTOP_VISUAL_GUIDE_DRAFT.md` 一樣屬設計驗證資料，不是第四層治理規則，也不得成為正式 CYInvoice 功能基準。
