CYInvoice 使用說明

一、啟動與資料
1. 本程式適用 Windows 10/11 x64，請直接執行 CYInvoice.exe。
2. 第一次在全新資料夾啟動時，必須先設定管理密碼及 MO店+ Excel 密碼。
3. 設定與發票紀錄存放於 Data；快取與紀錄分別存放於 Cache、Logs。
4. 請勿刪除或任意修改 Data 內的 JSON 檔案。搬移程式時，請連同整個 CYInvoice 資料夾一起搬移。

二、環境安全
1. 初次啟動固定使用光貿測試環境，不會開立正式發票。
2. 正式環境需在「設定」輸入公司統編、App Key，並以管理密碼確認。
3. App Key 與 MO店+ 密碼使用 Windows DPAPI 加密，只能由原 Windows 使用者解密。
4. 正式開立前，務必再次確認畫面上方的環境提示。

三、手動開立
1. 選擇一般消費者或公司統編，輸入訂單編號、買方資料與商品明細。
2. 公司統編發票可切換含稅／未稅輸入；已有明細會自動換算到小數點後最多 7 位。
3. 使用「預覽」核對內容，再按「開立測試發票」或「開立發票」。
4. 同一來源、同一原始訂單編號成功開立或結果不明後，程式會阻擋重送，避免重複開票。

四、Excel 匯入
1. MO店+、酷澎及鼎新 ERP 都會先開啟同一套批次確認視窗；只有原始 Excel 表頭與取用欄位依平台不同。
2. 請逐張核對並勾選；取消、未勾選或尚未完成解析的訂單不會送出。
3. MO店+ 使用設定內保存的 Excel 密碼唯讀解析；酷澎依已寄出訂單欄位解析。鼎新 ERP 在尚未取得實際樣本與欄位對照時會於確認視窗停止，不會送出資料。
4. 光貿測試環境送出時會保留原始 OrderId 供防重與核對；客戶、商品、聯絡資料及備註會去識別化，本機確認畫面及紀錄仍保留原始內容。

五、已開立發票清單
1. 預設查詢本月第一日至今天，可再依發票號碼、訂單、買受人、統編、來源與狀態篩選。
2. 「重新整理狀態」會向光貿查詢，不會改寫原送出時間，也不會自動重送結果不明的發票。

六、問題排查
1. 上方 API 狀態：灰色為查詢中、綠色為正常、紅色為異常。
2. 發生問題時請保留完整 CYInvoice 資料夾及 Logs，並先備份 Data。
3. 本程式僅限公司內部使用，禁止對外散布。
