## 1. 背景（使用者原話，2026-11-17）

V1.3.2 上線實測後：

> 1. 三個查詢分開是原型測試需要，正式查詢頁不分來源，只在表格裡面放一個來源或是可排序。
> 2. 比價總覽不應該是這樣，新增查價也是個完全無意義的功能，查價就很簡單：輸入框＋下拉選單查詢來源（全部或選一個），按查價就好，可顯示最近查價結果之類的。
> 3. 追蹤商品頁面也不理想，請整體評估並設計。

> 原本會有那個規格自己處理是因為查到的東西規格程式難以判斷……不能把設定規格功能拿掉。還是要有手動增加比價的功能，看是不是追蹤商品可以手動增加一筆比價。追蹤商品我的售價要有蝦皮／MO店+／酷澎三格，可以分別去跟三個來源比價，如果沒有填的話就不比價。

> 走勢圖想做在同一張，可以開啟不同平台的線，會疊在同一張圖上（不同顏色線條）呈現，可以連我們自己的售價也放上去。

> 酷澎用藍色，MO 用他品牌的那個桃＋紫混合那種顏色。

## 2. 已定案事項

### 2.1 頁面

左側導覽只留四頁：**查價**、**追蹤商品**、**待確認**（顯示待確認筆數徽章）、**操作紀錄**。移除「比價總覽」、「自動查價」兩頁與手動價格紀錄功能（新增查價、CSV 匯入匯出、`/api/records*`）。預設首頁為「查價」。

### 2.2 查價頁

- 頂部一列：關鍵字輸入框＋來源下拉（全部／momo／蝦皮／酷澎，預設全部）＋「查價」按鈕。Enter 等同按查價。
- 「全部」= momo 第 1 頁＋飛比一次（蝦皮、酷澎來自同一次飛比查詢）；沿用既有快取、間隔與冷卻（`querySource`）。
- 結果是**一張表**：來源（彩色小標籤）、商品名稱（連結）、賣家、價格、規格（解析或人工設定結果）、操作。來源、價格、商品名稱可點欄位標題排序；表格上方有來源篩選小按鈕（全部／momo／蝦皮／酷澎，顯示各自筆數）。
- 各來源狀態（被限制、節流、無結果、已用快取）以表格上方一行精簡提示呈現，不擋住其他來源結果。飛比的免責說明縮成一行小字。
- momo 有下一頁時，表格下方「載入更多 momo」。
- 每列操作：**設定規格**（沿用 `listing_classifications`，不可移除）、**不使用**（排除）、**加入追蹤**（開啟新增追蹤商品表單，預填名稱＝標題、共用關鍵字＝本次關鍵字、型號／包裝取自規格解析）。
- 依規格分類的同規格摘要（最低／中位／最高、筆數）保留，放在表格上方一行。
- 無查詢時顯示「最近查價」：最近 10 個不同關鍵字（取自 `search_cache`，全站共用），點擊即重查（10 分鐘內走快取）。

### 2.3 追蹤商品：資料

- 我的售價分三格：**蝦皮**、**momo（MO店+）**、**酷澎**，各自可空白；空白＝該平台不比價（仍顯示市場價）。
- 三個平台各有自己的商品連結（選填）。
- 售價只能透過「調整售價」修改，每次修改留紀錄（平台、舊價、新價、備註、操作者、時間）與 audit。
- 查詢關鍵字：一個**共用關鍵字**（必填），進階可個別覆寫「momo 關鍵字」與「飛比關鍵字（蝦皮、酷澎共用，因兩者來自同一次飛比查詢）」；覆寫空白時用共用關鍵字。
- 新增選填欄位「CY Web 品號」，本版只儲存與顯示；下一版用來連結 CY Web 商品（見 §4）。

### 2.4 追蹤商品：比價規則

- 每個平台獨立比較：我的該平台售價 vs **該平台**最新一次查價的同規格最低價、中位數。
- 差距% =（我的售價 − 市場最低）÷ 市場最低。高於市場最低 5% 以上顯示警示色，低於或相等顯示正常色。
- **手動比價**：追蹤商品內可手動新增比價紀錄（平台：蝦皮／momo／酷澎／其他、賣家、連結、價格、查價日期、備註），可修改、刪除，全部留 audit。查價日期在最近 30 天內者計入該平台的同規格比較；超過 30 天顯示為灰色「已過期，不計入」。「其他」平台只列出，不計入三平台比較。

### 2.5 追蹤商品：列表

- 每列：商品名稱＋型號／規格、三個平台欄（各顯示「我的售價／市場最低／差距%」，未設定售價者只顯示市場最低）、待確認筆數、上次查價、下次查價。
- 預設排序「最需要注意」：先依三平台中最大的正差距% 由大到小；再依待確認筆數由多到少；其餘依名稱。也可改依名稱、上次查價排序。
- 篩選：全部／需注意（任一平台差距 ≥ 5%）／有待確認／已停用。
- 單筆新增照舊（不做 CSV 批次匯入，下一版改由 CY Web 匯入）。

### 2.6 追蹤商品：詳情

由上到下：

1. 標題列：名稱、型號、規格屬性、包裝、CY Web 品號；按鈕「立即查價」「編輯」。
2. 三張平台卡：我的售價（含「調整售價」）、該平台同規格最低／中位數、差距%、計入筆數。
3. **走勢圖**（§2.7）。
4. 候選商品：分頁籤 待確認／同規格／其他包裝／不相關／不是同一商品，表格含來源欄，沿用既有判斷操作。
5. 手動比價表。
6. 售價調整紀錄（三平台合併，含平台欄）。

### 2.7 走勢圖

- **單一張圖**，橫軸為日期，縱軸為價格；上方以切換鈕控制每條線是否顯示。
- 市場線（每平台各一組）：同規格最低價（實線，預設顯示）、同規格中位數（同色虛線，預設隱藏）。資料來自每次查價該平台的同規格觀測值（`price_observations`，依 run 與 source 計算最低、中位）。
- 我的售價線（每平台一條）：同色粗階梯線，依售價調整紀錄畫，調價當天跳一階，延伸到今天；該平台從未設定售價則無此線。
- 手動比價：在對應平台顏色畫圓點（只畫三平台）。
- 平台顏色固定：**蝦皮 `#EE4D2D`（橘）**、**momo `#B5179E`（桃紫）**、**酷澎 `#346AFF`（藍）**。
- 滑鼠移到某日期時，一個浮動框同時列出當天所有顯示中線條的數值；手機可點按。
- 時間範圍切換：3 個月／1 年／全部。
- 以原生 SVG 繪製，不引入圖表套件。

### 2.8 待確認頁

- 列出所有追蹤商品的待確認候選（`latest_candidates.grp='pending'`），依商品分組，每組標題可連到商品詳情。
- 每筆可直接判斷（同規格／其他包裝／不是同一商品），操作與詳情頁相同；判斷後即時從清單移除並更新導覽徽章。

### 2.9 介面風格

沿用 V1.3 已定的 CY Web 商務風格與主色 petrol `#0F5E73`；平台顏色只用於來源標籤、走勢圖、平台卡左側色條，不作為大面積底色。桌面 1440 與手機 390 都要可用，手機表格可橫向捲動但頁面本身不得橫向捲動。
