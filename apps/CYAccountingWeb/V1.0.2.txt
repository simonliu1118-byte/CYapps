CYAccountingWeb V1.0.2（Build 0）
日期：2026-10-31（台灣時間）
狀態：依新需求將全帳簿搜尋結果整合至中央清單，待 PR 驗證及部署。

使用流程
- 搜尋列按鈕依序為「搜尋 → 全帳簿搜尋 → 清除」，清除在最右。
- 全帳簿搜尋視窗維持 400px，只輸入期間與關鍵字。成功後關閉視窗，中央清單直接顯示結果與分頁。
- 中央摘要明示搜尋期間及關鍵字，保留每頁 50 筆與前後頁；不把原月份合計冒充搜尋期間合計。
- 按清除直接還原原月份 snapshot 與正常餘額，清掉關鍵字，不另發查詢。
- 中央關鍵字搜尋在全帳簿模式下沿用已接受的期間；關閉未送出的條件視窗不改變現有結果。
- 切換月份、新增記帳或回到觸控呈現時離開全帳簿模式；清除、換月、取消後的舊回應不會重新顯示搜尋結果。

資料與呈現
- 同一 renderLedgerRow／writeLedgerRows 顯示月份與全帳簿結果，不新增第二個 #transactionRows renderer。
- 搜尋結果不替換 app.js 的月份 transactions／期初 snapshot。跨月部分結果的逐筆餘額顯示「—」，不捏造為 0 或用過濾後的資料重算；查看可透過既有月份載入與定位回到該筆。
- 搜尋列保留原帳戶配色與螢光標記，操作維持唯讀查看；進入該月後依原有權限進行帳務操作。
- 全帳簿結果固定日期新到舊；原月份的日期方向／帳戶分組狀態保留，清除後恢復。
- 拆除舊視窗結果表格、查看 listener、分頁 surface 與三欄結果 CSS；分頁直接由原 Toolbar owner 建在中央清單 header，不使用 DOM 搬移、observer 或包裝層。
- 手機／平板入口與原功能維持原樣；3 年（含起訖最多 36 個月）、資料庫日期索引及游標規則不變。

讀取與權限
- 沿用原 GET /api/transactions/search、單頁一個 SELECT、最多 50 筆加一筆 lookahead。只補回既有 marker_color／marker_target 欄位，沒有新增查詢、COUNT 或 OFFSET。
- 原 CYID／USER 唯讀／recovery hold 不變；無 migration、無資料寫入、schema 15。
- 清除及已查看頁面的往返不新增讀取；點查看才沿既有月份 GET 載入帳本。
- 本次開發正式 D1 讀取 0、寫入 0。三年候選量估算及 rows_read 界線沿 V1.0.1.txt，不將 LIMIT 50 當作只掃描 50 列。

驗證
- 本機 47 項 workflow 應用程式檢查通過；語法、metadata、whitespace 檢查通過。
- 搜尋回歸涵蓋中央列、清除還原原餘額及不重讀、原 snapshot 不變、空結果、標記、分頁、失敗保留舊結果、取消／清除後晚回覆、查看定位、換月與觸控退出。
- 實際對話框與中央 renderer 的合成 DOM 通過：按鈕順序、無視窗結果表格、中央分頁與列、成功關閉視窗、清除還原及 400px 上限。
- 實際瀏覽器幾何、原生選擇器及真機操作仍待人工驗收；不以 DOM 檢查宣稱已通過真機驗收。
