本檔保存可確認的歷史事實。正式 Release 為 V0.3.1（2026-10-17，tag `cyerp-auto-input-v0.3.1`），前一版為 V0.2.9（2026-10-12，tag `cyerp-auto-input-v0.2.9`）；先前發布的 V0.2.7（tag `cyerp-auto-input-v0.2.7`）已依使用者要求刪除，由 V0.2.9 取代。V0.2.6 以前皆為工程測試版。C# 重寫線（V0.1.0 起）於 2026-10-11 以 PR #104 squash merge 進 `main`（V0.2.0 Build 31），取代舊 Go 線 `V0.0.10 Build 19`；V0.2.1–V0.2.3 Build 1 以 PR #398、V0.2.4 以 PR #418、V0.2.5–V0.2.7 以 PR #421、V0.2.7 Build 1–V0.2.9 以 PR #423 合併。實機結果以 `WORK_HANDOFF.md` §4 為準。

## V0.3.2 — 2026/10/19（開發中）

- ERP：本程式自己按 F5 新增的單據，欄位讀到殘留文字時改為覆蓋，不再整張停止。

- Build 0（2026/10/19）：MO店+ 全自動三張新單都在「發票號碼」停止（使用者 LOG／截圖 2026-10-19）：ERP 畫面上發票號碼是空白，但程式讀到的控制項文字不是空的（ERP 控制項文字會殘留，先前送貨地址、貨運別也發生過），所以以「已有內容、避免覆蓋」停止並放棄單據。三張是各自遇到同一個原因失敗，批次本身有繼續下一張。現在只要單據是這次由程式按 F5 新增的全新單，欄位讀到的內容一律以表單值覆蓋（LOG 記下原內容）；開始時 ERP 已在輸入中的單據仍照舊停止，避免覆蓋人工輸入的資料。

## V0.3.1 — 2026/10/17（正式 Release：tag `cyerp-auto-input-v0.3.1`）

正式版，彙整 V0.2.9 之後的 V0.3.0 Build 1–26 並新增自動更新（使用者 2026-10-17 決定以 V0.3.1 發布）：

- 自動更新：程式開啟約 20 秒後及每 4 小時檢查 GitHub 上本專案較新的正式 Release（Actions 測試包不算），有就自動下載、核對 SHA-256，在沒有工作進行時替換程式並自動重新開啟；正在工作時等工作結束或程式關閉時再替換。設定、紀錄（Data）、Temp 與 LOG 都保留。
- 蝦皮「全自動」：自己開 Chrome 視窗，逐筆安排出貨、列印寄件單（蝦皮店到店／店到宅、7-11、全家）、擷取訂單並輸入 ERP，直到沒有待處理訂單；需要人工的訂單記下跳過，最後列出完成清單；買家備註符合關鍵字時以聊聊送出設定的訊息。
- MO店+ 全自動：批次出貨、存寄件單與新竹總表、匯出訂單，經 CYInvoice 開立發票，列印寄件單（全家／7-11 熱感裁切、新竹 A4）與紙本發票後批次輸入 ERP。
- 酷澎：匯入訂單匯出檔；測試流程可從「正在配送」全選下載 Excel 後開發票、列印並輸入 ERP。
- ERP：欄位改用貼上輸入（更快）；找不到銷貨單建立作業時從「作業速查」自動開啟，開著多個時用在檢視狀態的那個，行為與 CYERPAutoQuery 一致。
- 設定：發送訊息、滿件贈送、印表機（熱感／A4 由本機已安裝的印表機勾選）、CYInvoice 程式位置與紙本發票樣式。
- Temp 暫存檔保留 7 天；新竹到廠取貨總表列印紀錄保留 7 天、紙本發票列印紀錄保留 60 天。
