# CYapps

志遠（CY／Chihyuan）內部 Windows 工具原始碼儲存庫。

本儲存庫預計公開原始碼供檢視；授權條款以根目錄 `LICENSE` 為準。

## 專案

- `apps/CYAccounting`：志遠記帳系統
- `apps/CYEnvelope`：CY 信封列印工具
- `apps/CYInvoice`：CY 電子發票工具

`CYWatermark` 不屬於本公開儲存庫，僅保存在 Private repository `CYapps_pvt`。

## Repository rules

所有開發、分支、發行、命名及敏感資料規則請見 `REPOSITORY_RULES.md`。
