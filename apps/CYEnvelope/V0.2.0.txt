階段一：C#／WPF 重做基礎
- 建立全新 SQLite 資料模型，不遷移尚未上線使用的 Go 版測試資料。
- 保存聯絡人多地址、多電話、各地址上次使用電話與上次郵件種類的資料欄位。
- 匯入 368 筆離線三碼郵遞區號資料，無法辨識時回傳空值供介面保留原碼。
- 建立毫米座標的共用信封繪製器；預覽顯示紅色套版參考，列印內容只繪黑字、勾記與黑色方框／直排文字。
- 匯入 AITeam 正式 ENV SVG／ICO 資產。
- 建立 Windows 核心檢查程式，涵蓋郵遞區號、電話格式、SQLite 多地址／多電話保存及繪製器輸出。

驗證狀態
- Linux 上以 .NET 10 SDK + EnableWindowsTargeting 編譯專案和測試程式成功。
- 尚未在 Windows 執行測試程式，也未完成介面、列印連接、打包及實機試印。
- Go 版仍保留作行為對照。此版本尚無 C# 測試包與正式 Release。
