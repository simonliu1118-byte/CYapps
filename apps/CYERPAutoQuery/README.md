# CYERPAutoQuery — SMART ERP 自動查詢工具

以 Windows 桌面自動化唯讀查詢鼎新 SMART ERP：品號（INVI02，批號與歷史異動走 INVQ01）、品名、客戶（COPI01）、供應廠商（PURI01）、銷貨銷退單（COPR15／COPR16）、進貨退貨單（PURR18／PURR22）、未收款（ACRR18），以及 CY Web「進貨輔助」的銷售彙總與批次庫存。資料一律用 ERP 自己的「轉出 Excel」取得。可在本機視窗查詢，也可作為 CY Web 的查詢 Agent。介面與 CYERPAutoInput 一致。目前版本 V1.2.1。

## 使用方式

1. 開啟 `CYERPAutoQuery.exe`。ERP 已開著「品號資料建立作業」時須停在檢視狀態（不要在新增或修改中）；沒開時程式會從 ERP 主視窗「作業速查」開啟，ERP 沒開且設定了「ERP 登入」時會自動開啟並登入。
2. 右上角狀態標籤顯示 ERP 狀態。輸入品號（英文字母、數字與「-」），按「開始查詢 ERP」或 Enter。
3. 查詢期間實體滑鼠鎖定、畫面中央顯示「自動查詢中」；完成後表頭與明細列在主視窗。
4. 查無品號時顯示「查無此品號」。
5. 品號是批號管理（批號管理不是 N）時，會自動到「庫存狀況查詢作業 (INVQ01)」查各批庫存量，結果在下方「批號」頁籤。
6. 要看歷史異動時勾「查歷史異動」，可勾選並挑選起、迄日期；沒勾的日期不輸入 ERP，範圍不設上限（Web 端另有限制）。結果在「歷史異動」頁籤。
7. 查詢中按 **Esc** 可立即中止並解除滑鼠（不會替你按 ERP 的取消）。

## 品名查詢

1. 「查詢」下拉選「品名」，輸入品名中的文字（例如「穴位貼」），按「開始查詢 ERP」。
2. 程式在 ERP「設定查詢條件 → 進階設定」貼上條件 `(INVMB.MB002 like N'%穴位貼%')` → 確定 → 從「資料瀏覽」轉出 Excel。
3. 符合的品號列在下方「品名查詢」頁籤（品號、品名、規格、單位、庫存數量、標準售價）；雙擊一筆即用品號查完整資料（庫別、批號、歷史異動）。
4. 關鍵字不可包含 `' % _ [ ]`。筆數達到 ERP「總資料筆數限制」（預設 500）時會提示可能還有更多。

## 客戶查詢（COPI01）

- 「查詢」選「客戶代號」：輸入代號（英文字母、數字與「-」）查一位客戶的完整資料。
- 「查詢」選「客戶名稱」：輸入簡稱或全名中的文字，簡稱與全名都會查；結果列在「客戶查詢」頁籤，雙擊一筆查完整資料。
- 欄位：負責人、連絡人、TEL、FAX、統一編號、行動電話、部門別、業務人員、登記地址、送貨地址（含郵遞區號）、付款條件、發票聯數、課稅別、通路別、型態別、客戶描述。

## 供應廠商查詢（PURI01）

- 「查詢」選「廠商代號」：輸入代號（英文字母、數字與「-」）查一家廠商的完整資料。
- 「查詢」選「廠商名稱」：輸入簡稱或公司全名中的文字，兩者都會查；結果列在「廠商查詢」頁籤，雙擊一筆查完整資料。
- 欄位：廠商代號、簡稱、全名、版次、統一編號、TEL、FAX、E-MAIL、負責人、聯絡人、行動電話、採購人員、備註、廠商分類、付款方式、付款條件、匯款銀行（含名稱）、匯款帳號、發票聯數、課稅別、結帳日期、聯絡地址與帳單地址（含郵遞區號）、廠商描述。

## 銷貨銷退單查詢（COPR15／COPR16）

- 「查詢」選「銷貨銷退單」：輸入客戶代號，用「起」「迄」日期選擇器指定單據日期（未勾的日期不輸入 ERP）。輸入客戶名稱時先列出客戶，雙擊一筆再查該客戶的銷貨與銷退單；只查到一位客戶時直接查。
- 程式依序開啟銷貨單明細表（COPR15）與銷退單明細表（COPR16），設定客戶、日期與「全部」狀態後按即時報表並匯出 Excel，用完關閉兩個視窗。
- ERP 會把匯出檔存到 `C:\My Documents`（資料夾不存在時程式會建立），程式立即把檔案移到程式旁的 TEMP，讀完刪除。
- 結果在「銷貨銷退單」頁籤：上方是單據清單（銷貨與銷退，新到舊），點選一張後下方列出品項明細，單頭資料顯示在上方欄位表。

## 進貨退貨單查詢（PURR18／PURR22）

- 「查詢」選「進貨退貨單」：輸入廠商代號，用「起」「迄」日期選擇器指定單據日期（未勾的日期不輸入 ERP）。輸入廠商名稱時先列出廠商，雙擊一筆再查；只查到一家時直接查。
- 程式依序開啟進貨單明細表（PURR18，設定廠商、日期與「全部」狀態）與退貨單明細表（PURR22，沒有廠商條件，只設日期，整份轉出後只留這家廠商），流程與檔案處理同銷貨銷退單。
- 結果在「進貨單」頁籤：上方是進貨與退貨單（新到舊），點選一張後下方列出明細；退貨明細有「原進貨單」。

## 未收款查詢（ACRR18）

- 「查詢」選「未收款」：輸入客戶代號查單一客戶；輸入客戶名稱先列出客戶（只有一位時直接查）；空白則查全部客戶。
- 「查詢」選「業務未收款」：輸入業務員代號，查該業務員要收的款項。
- 帳款截止日期使用 ERP 預設（當天）。流程與檔案處理同銷貨銷退單查詢，用完關閉 ACRR18 的兩個視窗。
- 結果在「未收款」頁籤：上方是結帳單，點選一張後下方列出它包含的憑證（銷貨單／銷退單）。

## 進貨輔助（CY Web，COPR15／COPR16＋INVI02）

- 只由 CY Web「進貨輔助」頁送出（類型 `RESTOCK`，使用者 2026-10-20）：單據日期起訖都要填，最多 31 天。
- 銷貨單明細表（COPR15）與銷退單明細表（COPR16）各跑一次，客戶代號起訖清空（全部客戶），條件與單一客戶查詢相同（進階選項確認／結帳狀態「全部」）。
- 依品號、日期加總銷貨數量與銷退數量（含贈／備品量，另附其中的贈品部分），再以 INVI02 批次查庫存數量（使用者 2026-10-20）：F6 → 進階設定貼上所有品號以 OR 連接的條件 `(INVMB.MB001 = N'…')` → 確定 → 資料瀏覽「轉出全部」一次取得，每批最多 100 個品號；條件框字數上限（EM_GETLIMITTEXT）不夠或貼上後讀回被截斷時，該批減半重試。最多查 500 個品號，連續 3 批失敗就停查其餘，查不到的庫存回報原因。
- 回報最多 500 個品號，依品號排序。
- 查詢中回報進度（`POST …/progress`）：報表完成幾張、已查庫存幾個品號，CY Web 頁面顯示「已查庫存 x / y 個品號」。

## ERP 自動登入與閒置關閉

- 主視窗右上「ERP 登入」：選 ERP 程式、填帳號密碼與登入公司、設定閒置關閉分鐘（建立作業預設 10、ERP 預設 30，0 表示不關閉），可勾「開機時自動開啟本程式」。
- 查詢時找不到 ERP 會自動開啟並登入；ERP 沒有回應會強制關閉重開後再試一次。
- 登入後 ERP 顯示「人數已滿」時，程式會按掉訊息（ERP 隨即自行關閉），查詢停止並回報「ERP 人數已滿」。
- 閒置以最後一次查詢與這台電腦最後一次鍵盤滑鼠操作較晚者起算，有人在用電腦就不會關閉 ERP。

### ERP 行程診斷（唯讀）

在「ERP 登入」設定視窗按「行程診斷（唯讀）」，可掃描目前可存取的 ERP 候選行程、PID／父 PID／工作階段、啟動時間、記憶體與 ERP 視窗類型。勾選「每 2 秒觀察變化」後，人工正常關閉並重新開啟 ERP，工具會記錄行程新增、消失與視窗變化；按「匯出遮蔽報告」儲存 TXT，提供排查 ERP 行程關係。掃描為唯讀，不會啟動、關閉、強制終止或重新登入 ERP。報告不含帳戶原文、完整檔案路徑、命令列或原始視窗標題；跨工作階段或權限不足的資訊可能無法讀取，並不代表行程不存在。**此功能本身不會改變自動登入、閒置關閉或異常重啟的行為。**

### ERP 沒有回應時的強制重開

- 只結束「擁有 ERP 主視窗或品號／客戶／廠商作業視窗、且和本程式同一個 Windows 工作階段」的程式，不看程式名稱或資料夾；ERP 伺服器上沒有 ERP 視窗的服務（SMDispatcher、SMCounterS、AUC 等）與其他遠端桌面使用者的 ERP 都不會被碰到。
- 先送關閉訊息，5 秒還沒結束才終止該程式（不連子程式），作業的程式先、主視窗的最後；LOG 會記下每個 ERP 視窗屬於哪個程式。

### CY Web 關閉／暫停 ERP

- CY Web 的 ERP 查詢頁右上「查詢程式」可要求「立即關閉」「關閉 15／30／60 分鐘」「關閉到…（自選時間）」「強制關閉 ERP」。本程式在佇列跑完後關閉 ERP（與閒置關閉相同；ERP 詢問未存檔內容時保留），強制關閉則結束 ERP 程式；結果回報 CY Web。
- 暫停期間不會自動開啟 ERP。暫停中在 CY Web 送出的查詢可「加入佇列」，CY Web 在暫停結束後才派給本程式，程式這邊不需要另外設定。
- ERP 閒置後顯示「因閒置而登出授權」時，詢問是否重新登入授權按 Yes，「無法開啟作業程式」按 OK，然後照常查詢。

## 自動更新

- 比照 CYERPAutoInput：程式會自己到 GitHub 找更新的正式 Release（測試包不算），下載並核對 SHA-256 後，在沒有查詢進行中時自動換新版並重新開啟；有工作時改在關閉程式時更新。Web 連線設定、TEMP 與 LOG 會保留。
- 看得到的更新過程（使用者 2026-10-20，兩個程式相同）：找到新版時主視窗上方出現提示條（轉圈動畫）「發現新版 V…，下載中…」，下載核對完成改為「已下載，程式閒置時會自動更新」；閒置時先跳出置頂倒數視窗，10 秒後自動更新，可按「立即更新」或「稍後再更新」（延後 30 分鐘），倒數中開始工作就取消、等下次閒置。更新時 PowerShell 顯示置中的「正在更新…」視窗與進度條：先備份會被覆蓋的檔案再複製，複製失敗就還原備份。無論成功或失敗都會重新開啟程式；成功時提示條顯示「已更新到 V…」10 秒，失敗時顯示「更新失敗，可能需要手動更新」（可按 ✕ 關閉），8 小時後再自動嘗試。
- 第一次請從 GitHub Release 手動安裝目前正式版（V1.2.1），之後的正式 Release 會自動更新。

## CY Web 查詢（Agent）

- 主視窗「Web 連線」：填 CY Web 網址、CY Web 超級管理員在「ERP 查詢」頁產生的 Token（只顯示一次），勾選「啟用 Web 查詢」。Token 以 Windows DPAPI 加密存在 `config/agent.json`（換電腦或換 Windows 帳號需重新設定）。
- 啟用後程式每 3 秒向 CY Web 領一次查詢工作，用與本機相同的流程查詢並回報；狀態列顯示「Web：已連線／查詢中／連線失敗」。
- 只回傳約定的欄位（`ItemFieldCatalog`）；失敗只回固定錯誤代碼，不送出本機訊息或路徑。
- 本機正在查詢時不領工作；Token 被拒時停止連線，需重新設定。
- 領工作時告訴 CY Web 本程式支援的查詢類型（`ITEM_NO` 商品、`ITEM_NAME` 品名、`CUSTOMER_NO`／`CUSTOMER_NAME` 客戶、`SUPPLIER_NO`／`SUPPLIER_NAME` 廠商、`SALES` 銷貨銷退單、`ORDER` 單筆單據、`PURCHASES` 進貨退貨單、`RECEIVABLE` 未收款、`RESTOCK` 進貨輔助），CY Web 只派這些工作；舊版本程式只會領到商品查詢。
- 「標準進價」只在 CY Web 工作帶 `includeCost:true`（該員工有「ERP 商品成本」權限）時才送出。
- CY Web 可在工作帶 `includeHistory`、`historyFrom`、`historyTo`（yyyy-MM-dd，可省略）要求歷史異動；回報另含 `batchManaged`、`batches`、`history`（欄位＋列，最多 2,000 列保留最新）。舊版 CY Web 會忽略這些欄位。
- Contract：chihyuan-web `docs/architecture/ERP_ITEM_QUERY_BRIDGE_CONTRACT.md`。

## 自動化流程（品號查詢）

```
找到 INVI02 視窗（ERP 開著其他作業不影響；多個時用處於檢視狀態的那個；沒有時從主視窗「作業速查」輸入 INVI02 開啟）→ 最大化並帶到前景
-> 確認在檢視狀態、沒有其他對話框
-> F6 開啟「設定查詢條件」（已開著就直接用）
-> 切到「一般選項」（視窗會記住上次頁籤；已在一般選項就不點）
-> 品號條件設為「=」，輸入品號並讀回確認
-> 確定，等查詢視窗關閉
-> 確認表頭品號 = 查詢品號；ERP 轉到資料瀏覽且品號空白（0.8 秒不變）即為查無此品號
-> 切到「基本資料1」（從資料瀏覽轉出不含庫別）
-> Ribbon「Excel」→「轉出至 Excel」
-> 匯出設定：確認格式為 xlsx；「單頭」「單身」各按一次「全選」（儲存設定會記住別人改過的勾選）；儲存檔案填入程式旁 TEMP 資料夾的新檔名 → 確定
-> 「檢視Excel資料?」按 No（按 Yes 會真的開檔）
-> 讀取單頭資料與單身資料，立即刪除暫存檔，再次確認品號沒變
-> （批號管理或要查歷史異動時）Ribbon「串查」→「庫存狀況查詢作業」（兩個同名取最上面）→ 等 INVQ01 開啟並確認帶出同一品號 → 最大化
   -> 「查各批庫存量」→「開始查詢」→ 等標題變成「…-查各批庫存量」且顯示查詢結果 →「轉出到Excel」→ 讀取後刪檔
   -> （要查歷史異動時）「查歷史異動」→ 選擇日期起、迄（讀回確認）→「開始查詢」→「轉出到Excel」→ 讀取後刪檔
   -> 關閉 INVQ01（失敗或 Esc 也會關）
-> 列出結果
```

## 讀取方式

- 資料來自 ERP 匯出的 xlsx，由程式自己解析（不需要 Excel 或 OpenOffice）。欄位名稱就是 ERP 的欄位標題（例如「品名」「標準售價」「售價定價一」「商品描述」）；日期欄轉成 yyyy/MM/dd。
- 每次匯出前在「單頭」「單身」各按「全選」，不受別人改過的勾選影響。
- 只保留 `ItemFieldCatalog.cs` 列的欄位（使用者 2026-10-16 指定），其他欄位（成本、庫存金額等）解析後立即丟棄；這份清單也是之後 Web 的欄位白名單。
  - 單頭：品號、品名、規格、單位、庫存數量、商品分類（ERP「商品」）、商品分類名稱（料件分類三名稱）、商品描述、條碼編號、批號管理、有效天數、主供應商、主供應商名稱、標準進價、標準售價、售價定價一～六。
  - 庫別：庫別、庫別名稱、儲位、安全存量、經濟批量、上次盤點日、最近入庫日、最近出庫日。
  - 批號（INVQ01 查各批庫存量）：批號、庫存數量、入庫日、有效日期。
  - 歷史異動（INVQ01 查歷史異動）：日期、單別-單號-序號、庫別、庫別名稱、入出別、異動數量、備註；單位成本、異動金額不讀。
  - 匯出缺少清單中的欄位時停止並列出缺少哪些，不回傳不完整的結果。
- 頁籤：先點已量測的固定位置，點完確認該頁籤真的顯示；沒有顯示才用 OCR 讀頁籤列找文字再點。
- Ribbon「Excel」與選單「轉出至 Excel」不是 Win32 控制項，以 OCR 找文字點擊（同 CYERPAutoInput 的「列印 → 直接列印」）；點錯 Ribbon 可能觸發其他功能，所以不用固定座標。先只辨識按鈕所在的群組（記住過的群組，或與按鈕同名的群組）；需要讀整條 Ribbon 時只截到群組下緣，不含下方資料欄位（某些資料文字會讓辨識元件出錯），仍失敗就逐個群組辨識。
- 每次點擊前都確認該點沒有被其他視窗遮住。
- 與其他 CY ERP 自動化程式共用一把機器層級鎖，避免兩支程式同時操作 ERP。

## 檔案

- `logs/CYERPAutoQuery_YYYYMMDD.log`：本機 LOG，預設只記錄長度，不記錄品號與欄位內容。
- `config/agent.json`：CY Web 連線設定（Token 已加密，不要複製到其他電腦）。
- `config/erp.json`：ERP 登入設定（密碼以 Windows DPAPI 加密，不寫入 LOG）。
- `TEMP/`：ERP 匯出暫存，讀完立即刪除（含成本、庫存金額，不要手動保留）。
- `runtime/ocr/*.onnx`：PaddleOCR 模型（與 CYERPAutoInput 相同），Ribbon／選單與頁籤備援使用。

## 開發

- C# / .NET 8 / WinForms，Windows x64 self-contained 單檔。
- 單元測試：`dotnet test tests/CYERPAutoQuery.Tests/CYERPAutoQuery.Tests.csproj`（純邏輯，任何 OS 可跑）。
- OCR 模型：`tools/fetch-ocr-models.ps1` 依 `tools/ocr-models.json` 下載並核對 SHA-256。
- 圖示：`tools/fetch-canonical-icon.ps1` 從 AITeam CY Icon Family 固定 revision 下載 `AutoQ.ico` 並核對 SHA-256（不進 Git）。
