CYInvoice V3.0.2 工程測試版內容（未正式 Release）

本批獨立 Patch：跨機待辦最小視窗欄位配置
- V3.0.1 已完成版本追蹤補正；本批是下一項獨立 WinForms UI 缺口，因此 VERSION 推進至 3.0.2，BUILD 回到 0，不當作上一項返修。
- 「跨機待辦」原七個固定欄寬合計 895px，最小視窗寬 740px 時產生不必要的水平溢出。調整成依實際 ListView 可用寬度比例配置，並為垂直捲軸預留空間；視窗縮小／放大時保留工作項目 ID 顯示區域。
- WinForms 啟動 smoke 在真實的跨機待辦控制項上驗證標準及最小視窗下的七欄總寬度、ID 欄可用空間與回查按鈕，不使用正式憑證、真 D1 或網路。

沿用 3.1 非折讓 Source 預覽
- 包含前一工程版已整合的 VOID／UPLOAD_ISSUE 匿名人工回報、CYID 管理員跨機清單／單筆 ID 查回、人工覆核與封存、修訂版競態檢查及 append-only Audit 原始碼。
- 人工封存僅是例外工作項目結案，並不等於光貿（AMEGO）已作廢、上傳成功或允許再送。結果不明只以原 ID 回查，不盲目重送；單筆讀取只傳必要七欄。

部署、實機與發行限制
- 本版是 Engineering／Preview；正式發行仍為 V3.0.0。Work Item schema16 SQL 僅在 draft，原 D1／Worker 尚未由本機 MCP 升級，WORK_ITEMS_ENABLED 預設關閉，跨機服務尚未正式啟用。
- 比例欄寬通過工程 smoke 不代表真實 100／125／150% DPI 或雙實體 Windows 已驗收；請依 TODO／V3.1 交接補實機證據。真實 Email 與異機災復亦保留 V3.0.0 已知限制。
- 未建立本版正式 tag／Release。完成原 D1 受控切換、真人驗收及剩餘 3.1 項目後，才可評估 Minor V3.1.0，並須使用者當次明確批准正式發布。
